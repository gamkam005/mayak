Задержка — короткий запрос через сервер (как «реальная задержка» в v2rayN): сервер отвечает. Загрузка — 256 КБ одним соединением: сервер реально качает. ТСПУ замораживает соединения с сетями многих хостингов после ~16 КБ: такой сервер отвечает, но поток встаёт — статус «заморожен», в автовыборе он последний. AS❄ — сеть в списке замороженных по внешним замерам (freeze-check). При сбое активного сервера он сразу проверяется ещё 2 раза (и загрузка тоже); ни одного нормального ответа — сервер выпадает. Если умер выбранный вручную — включается автовыбор.
