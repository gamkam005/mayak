МАЯК для Windows 0.3.2
======================

Как запустить (2 шага)
1. Откройте link.txt, вставьте одной строкой ссылку mayak://… от вашего сервера, сохраните.
   Нет своего сервера — оставьте как есть: МАЯК пойдёт напрямую с обманом DPI,
   а где не выйдет — через бесплатные подписки (VLESS/VMess/Trojan/SS/Hysteria2).
2. Дважды щёлкните mayak.exe.
   Откроется окно МАЯК и панель в браузере (http://127.0.0.1:9090/).
   Системный прокси Windows включается сам — Chrome, Edge, Telegram Desktop
   (с «системным прокси») и большинство программ сразу идут через МАЯК.

Как остановить
- Закройте окно МАЯК (или Ctrl+C в нём). Системный прокси вернётся как был.
- Если окно спрятано/зависло — stop.bat (остановит и выключит прокси).

Что делает двойной щелчок (режим «просто работай»)
- маршрут auto: сначала напрямую с обманом DPI, не вышло — через ваш сервер;
- если ваш сервер не отвечает — запасной вход через бесплатные подписки
  (7 встроенных списков; проверка серверов идёт в фоне, лучшие сохраняются в mayak-subs\);
- в панели можно: сменить режим подписок (выкл / резерв / всегда), выбрать или закрепить сервер,
  отключить списки, добавить свои ссылки — всё сохраняется в subs.json рядом с программой.

Обновления
- МАЯК сам проверяет GitHub через 30 с после запуска и раз в 6 часов.
  Вышла новая стабильная версия — скачает, проверит подпись и контрольную
  сумму, заменит mayak.exe и перезапустится в том же окне. link.txt и
  subs.json не трогаются. Бета-версии не ставятся.
- Выключить: создайте рядом пустой файл noupdate (или флаг -noupdate).
- Вручную: mayak.exe update   (только проверить: mayak.exe update -check)
- Если папка МАЯК лежит там, куда нельзя писать (Program Files), обновление
  не сработает — держите её, например, на Рабочем столе.

Файлы
- mayak.exe          — программа (клиент + панель + ядро Xray для подписок)
- link.txt           — ваша ссылка mayak://… (никому не показывайте)
- subs.json          — настройки подписок (меняются из панели)
- autostart-on.bat   — запускать МАЯК при входе в Windows (свёрнутым окном, без браузера)
- autostart-off.bat  — убрать из автозапуска
- stop.bat           — остановить МАЯК и выключить системный прокси
- proxy-on.bat / proxy-off.bat — включить/выключить системный прокси вручную
  (127.0.0.1:1080), если запускаете mayak.exe с флагами без -sysproxy

Для продвинутых
  mayak.exe client -link "mayak://…" -route tunnel -subs off -sysproxy
  mayak.exe client -h        — все флаги
  Прокси: SOCKS5 и HTTP на 127.0.0.1:1080 (можно указать в любой программе).
  Обман DPI на Windows: работают только перекройка TLS-записей и разрез TCP
  (tlsrec, split, multirec). fake/disorder/oob требуют Linux/Android/роутер.

Если Windows Defender/SmartScreen ругается — «Подробнее» → «Выполнить в любом случае».
